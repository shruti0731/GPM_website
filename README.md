# 🏫 GPM Website

## 📖 Project Overview
The GPM Website is a modern, responsive web application developed for Government Polytechnic, Miraj (GPM) to provide an accessible and user-friendly online presence.
It serves as an informative and interactive portal that highlights the institute’s courses, departments, staff details, announcements and student resources.

This project was developed with the goal of improving digital accessibility and engagement for students, faculty and visitors.
---

## 🏗️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript, Bootstrap  
- **Backend:** Firebase (for data storage and hosting)  
- **Version Control:** Git and GitHub  

---

## ✨ Features
- **Home Page:** Introduction to GPM with highlights and announcements  
- **Departments Section:** Details of each department, faculty info, and labs  
- **Gallery:** Photo section for college events and activities  
- **Contact Page:** Embedded Google Maps, contact form, and college details  
- **Responsive Design:** Works seamlessly on mobile, tablet, and desktop

## ⚙️ Setup Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/shruti0731/GPM_website.git
   ```
2. Navigate into the project folder:
   ```bash
   cd GPM_website
   ```
3. Open the `index.html` file in your browser.
